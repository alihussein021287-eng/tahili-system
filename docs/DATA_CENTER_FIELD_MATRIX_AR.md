# مصفوفة مطابقة قوالب الاستيراد لحقول النظام (قالب 2.0)

المرجع المعتمد لكل نوع هو سلوك النظام الفعلي (نموذج التسجيل + التحقق في الخادم + مخطط قاعدة البيانات). تعريف القالب والتحقق والتنفيذ في ملف واحد: `src/lib/data-center/registry.ts`، وقوائمه من `labels.ts` و`permissions.ts` و`validate.ts` وقاعدة البيانات الحيّة.

التصنيف: **مطلوب** / اختياري / مرجع (قائمة من النظام) / مولَّد / غير مدعوم / محظور.
