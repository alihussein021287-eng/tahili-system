# دليل سجلات الموظفين وربط الحسابات

المسار: الموظفون والمهام ← سجلات الموظفين (`/staff/employees`).

- **السجل (Employee)** هو الشخص الوظيفي المستورد من الإكسل (مقيم، اختصاص، موظف). **الحساب (User)** هو بيانات الدخول. لا يحمل السجل صلاحيات.
- الأعداد في أعلى الصفحة تفصل: سجلات الموظفين، المقيمون، الاختصاص، الآخرون، السجلات بلا حساب، الحسابات (فعالة/معطلة).
- تعيين الأدوار (مراجعة فقط): أطباء التدرج = RESIDENT، الاختصاص = DOCTOR؛ الموظفون لا يُقترح لهم دور إلا بمطابقة تامة للمسمى، وغير ذلك يحتاج قراراً بشرياً. شاشة «مراجعة تعيين الأدوار» لا تطبّق شيئاً.
- **ربط حساب موجود:** اكتب اسم المستخدم بدقة ← راجع الأدلة (الاسم مطابق، الفرع نفسه، الدور متوافق، السجل والحساب غير مرتبطين) ← اكتب كيف تحقّقت من الهوية ← تأكيد. الهاتف أو تشابه الاسم وحده لا يكفي.
- **تجهيز حساب:** يُنشأ معطّلاً مرتبطاً بالسجل نفسه (لا سجل مكرر) وبفرعه؛ عضوية المركز اختيارية وصريحة؛ بدونها لا وصول لأي مركز. التفعيل يتم لاحقاً من صفحة الحساب بالمسار الآمن المعتاد.
- ADMIN وMANAGER لا يُجهَّزان من هنا.

## التنقل الموحّد (09.4)
«الموظفون والمهام» هو المدخل الرئيسي: نظرة عامة ← سجلات الموظفين ← الحسابات والأدوار ← الحضور ← الدوام ← الإجازات ← المهام ← التقارير. كل تبويب يفتح صفحته الحالية بصلاحيتها الخاصة؛ إدارة الحسابات تبقى `/users` (مدير النظام) وصفحة الحساب بتبويباتها الخمسة (معلومات الشخص، مراكز العمل، الصلاحيات، الأمان، النشاط) كما هي. الصلاحيات العامة والتدقيق وإعدادات الأمان تبقى تحت «النظام». أعداد السجلات منفصلة عن أعداد الحسابات، ويُحسب كل شخص مرة واحدة.
