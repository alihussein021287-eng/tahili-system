# إغلاق نطاق V1 — قرار المالك 2026-10-27

الأساس 3d88c3b؛ تنفيذ محلي فقط دون تعديل PR17 أو QA أو الإنتاج. هذه مواصفة وظيفية قبل التنفيذ، مستقلة عن تحسين العرض.

- SERVICE داخل V1: ADMIN يعيّن مسؤولاً فعالاً من دور الخدمة الموجود فعلاً في CENTER_STATIONS وفرع فعال محدد. صلاحية services.designate لا تمنح الإسناد أو التنفيذ؛ خدمات services.assign وservices.execute مستقلة وافتراضيها المنع. مسؤول التعيين يحتاج services.assign، والممارس يحتاج services.execute مع الدور والفرع الفعالين ونطاق المراجع. لا self-assignment، ولا مسؤول عام، ولا تجاوز مدير. SERVICE خارج الكتالوج أو بدور غير مطابق يبقى محجوباً. UUID لكل تعيين مسؤول ولكل إسناد عمل، وسحب مدقق لا يمحو التاريخ؛ سحب المسؤول يبطل تنفيذ الإسناد الذي نشأ منه حتى تسوية جديدة صريحة. لا تمحى إنجازات مكتملة لإعادة إسنادها.
- إكمال SERVICE السريري توثيق تشغيلي فقط دون تأكيد طبي مفترض؛ Reception/Finance الموثقتان صراحة بكونهما غير سريريتين يمكن إنهاؤهما تشغيلياً. لا تغيير لعقد CENTER أو SPECIALIST_REVIEW. جميع كتابات SERVICE الجديدة تقفل الفرع ثم المرحلة، وتتثبت من المصدر والصلاحيات الحالية.
- NI01 داخل V1: تسجيل موافقة على إجراء محدد للمراجع، مع رمز المستند وإصداره واسم الموقّع وصفته وسند تمثيله عند الحاجة وتاريخ التوقيع والموظف المسجل. يتعهد المسجل أن الملف نموذج موقع فعلاً؛ لا شهادة توقيع إلكتروني قانوني. ملفات PDF/PNG/JPEG فقط، تتحقق بصمتها ونوعها وتفحص ClamAV قبل القبول. صلاحيات consents.record/view/withdraw مخصصة وافتراضيها المنع، مع صلاحيات الملفات القائمة والنطاق الحالي للمراجع. المسؤول المخول يمنحها للحسابات المناسبة عبر إدارة الصلاحيات؛ لا نستنتج سلطة تسجيل من اسم الدور وحده. لا اشتراط موافقة شامل جديد لأي إجراء.
- كل موافقة لها دليل مستقل غير قابل للاستبدال؛ النسخة الجديدة سجل جديد، ولا يسمح بتكرار رمز/إصدار المستند للمراجع نفسه. السحب يحتاج سبباً ويحفظ السجل والملف والتدقيق. التنزيل المحمي يتطلب صلاحية حالية ونطاق المراجع وبصمة ملف صحيحة وتدقيقاً؛ لا وصول عبر مشاركة التعاون أو رابط تخزين مباشر. التخزين غير ذري مع DB؛ فشل المعاملة قد يترك blob خاصاً غير مرتبط، دون سجل موافقة ناجح أو ملف عام؛ لا حذف تلقائي في هذه المهمة.
- NI03: يؤجل التكامل الخارجي LIS/PACS خارج V1 بقرار المالك، دون تسميته PASS. تبقى دورات الإحالات والنتائج الداخلية القائمة كما هي. لا مصدر يثبت اعتماداً إلزامياً عليها في اليوم الأول ضمن التعريف الأصلي المسترجع.
- 44px: تصحيح min-height القائم للأزرار والحقول في نمط الموبايل؛ لا إعادة تصميم. يبقى فحص 44px كما هو مع RTL وdesktop/mobile والثيم وعدم overflow.
- التحقق: PostgreSQL اصطناعي fresh/additive، SERVICE إيجابي وحراس وسحب/تكرار/rollback، NI01 دليل موقع اصطناعي وفحص بروتوكول scanner وعزل الملف والسحب، رجوع CENTER/END متأثر فقط، TypeScript ثم تجميد SHA وبناء Linux واحد. لا اعتماد ذاتي؛ جلسة مستقلة جديدة تراجع المرشح النهائي.
