# خطة QA النظيفة وUAT — دون تنفيذ

المدخل هو الـSHA النهائي وحزمة المراجعة وقائمة الترحيلات وبصمة الصورة المطابقة. لا يجيز هذا الملف تشغيل أو ترحيل QA أو الإنتاج.

## قبل QA

1. مراجعة Codex مستقلة للفرق الجديد والمصدر التراكمي وتبعيات الترحيل. لا تنقل موافقة الأساس إلى التنفيذ الجديد تلقائياً.
2. تفويض QA صريح وبيئة اصطناعية منفصلة بقاعدة وvolumes جديدة؛ لا استبدال أو حذف لأي قاعدة/volume QA قائم. احم PostgreSQL وMinIO وClamAV وصور التشغيل الحالية.
3. تحقق من SHA والصورة Linux/amd64 ووسم المراجعة وملف package-lock وقائمة الترحيلات الـ37. اعزل بيانات وملفات الاختبار وأسرار البيئة؛ لا تنسخ بيانات مرضى حقيقية.
4. اختبر نقطة استرداد متماسكة. أوقف كل كتّاب النسخة القديمة في نافذة الترحيل المصرح بها؛ لا mixed-version. طبّق migrate deploy ثم التطبيق المتوافق فقط بعد نجاح فحص المخطط والقراءة.
5. افحص محرك ClamAV الحقيقي وحداثة تعريفاته وحدود الرفع ونطاق التخزين الخاص والتنزيل؛ محاكي INSTREAM المحلي ليس دليلاً على تعريفات حية.
6. أنشئ حسابات UAT اصطناعية. امنح مفاتيح SERVICE وconsents المخصصة للحسابات المخولة فقط عبر إدارة الصلاحيات؛ لا تمنح journey.confirm أو اعتماداً طبياً كأثر لتعيين مسؤول خدمة أو لتسجيل موافقة.

## UAT المالك

- ADMIN يعيّن مسؤول المالية في فرعه؛ مدير آخر أو مستخدم يملك مفتاح designate دون دور ADMIN يُرفض. اسحب المسؤولية واستبدلها وتحقق من الفاعل والتوقيت والتدقيق.
- المسؤول يعيّن ممارساً آخر مؤهلاً؛ يرفض نفسه والدور/الفرع/المركز الخطأ والحساب غير الفعال. الممارس يبدأ وينهي العمل. يسجل LAB إنجازه تشغيلياً دون اعتماد طبي. جرب طلباً قديماً بعد سحب المسؤول أو استبدال UUID.
- اختبر السبب المطلوب لتسوية إسناد غير مكتمل بمصدر مسحوب. لا تعِد إسناد أو تمحُ إنجازاً مكتملاً. تحقق أن التسليم والمسار العام لا يتجاوزان الحراسة الجديدة.
- سجّل نموذج موافقة موقعاً اصطناعياً فعلياً للمراجع والإجراء الصحيحين، مع رمز/نسخة واسم الموقّع وصفته وتاريخه. عند التمثيل تحقق من سند الصفة. لا تُدخل معلومات حقيقية في اختبار QA.
- جرّب نسخة أخرى دون محو الأولى، ثم سحباً بسبب واضح. راجع بقاء الدليل والبصمة والفاعل والتاريخ، وأن السجل المسحوب لا يعود SIGNED. لا تنسب اعتماداً قانونياً إلكترونياً للنظام.
- جرّب التنزيل المصرح، ومستخدم فرع آخر، وسحب المفتاح، وملفاً مرفوضاً أو فحصاً غير متاح. لا وصول عبر مشاركة التعاون أو عنوان تخزين مباشر. جرّب ملفاً ممسوحاً كبيراً ضمن الحد المضبوط عبر واجهة الرفع الحقيقية.
- أعد المسار الإيجابي المعتمد لـCENTER وEND فقط: ترشيح → قبول الطبيب → إنجاز مستقل → تأكيد، وقفل تعديل جلسات المقيم بعد الإنجاز، دون تحويل حالة المرحلة عند إغلاق البرنامج تلقائياً.
- اختبر هاتفاً وسطح مكتب، RTL والثيم والتركيز باللوحة، 44px بلا overflow. سجّل النتائج الفعلية والأدوار والحالات لا مجرد صفحة 200.
- NI03 الخارجي خارج V1 ومؤجل؛ تحقق من عمل دورات المختبر والأشعة الداخلية القائمة دون ادعاء LIS/PACS أو نظام عينات مستقل جديد.
